# 1.2-agent-mode

## Concepts
- Agent mode can edit files and run terminal commands autonomously, but
  always proposes the change/command first and waits for approval —
  it doesn't act silently.
- This is the same "confirm before acting" pattern you'll see again with
  MCP tool calls (Phase 1.4) and later with real autonomous agents
  (Phase 5) — a recurring safety pattern, not a one-off UI quirk.

**Intuition:** Agent mode is like a very competent assistant who drafts
an email and shows it to you before hitting send, every single time —
never sends on your behalf without that final look.
