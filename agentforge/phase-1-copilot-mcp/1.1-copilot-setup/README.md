# 1.1-copilot-setup

## Concepts
- Copilot has 4 core interaction modes: ghost-text completions (Tab to
  accept), Ask mode (questions, no file edits), Agent mode (can edit
  files + run terminal commands), and inline chat (Cmd+I, targeted
  single-line help without opening the full panel).
- Context references (`#file`, `#selection`, `#codebase`) tell Copilot
  what to actually look at — without them, it only sees the currently
  open file.

**Intuition:** Ghost-text is like a very fast autocomplete that guesses
your next few words. Ask mode is a colleague you're chatting with over
Slack — they can look and advise, but can't touch your keyboard. Agent
mode is that same colleague, but now with your login — they can actually
make changes, which is exactly why it always shows you what it's about
to do before doing it.
